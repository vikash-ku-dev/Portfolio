## ▣ Run locally

No build tools or package installation are required.

1. Clone or download this repository.
2. Keep `index.html`, `style.css`, and `script.js` together in the same folder.
3. Open the folder in VS Code.
4. Run `index.html` using the **Live Server** extension, or open the file directly in a browser.

```text
portfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

> If your current version still has CSS and JavaScript inside `index.html`, it will run as a single file. For the split-file version, make sure the HTML links to `style.css` and `script.js` using those exact filenames.
